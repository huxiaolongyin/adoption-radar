PowerToys 是我在 Windows 上选择性使用的效率工具集。目前稳定进入工作流的模块包括命令面板、窗口置顶、File Locksmith 和 Hosts 文件编辑器，分别承担统一启动入口、多窗口参考和常见系统排障。

这些需求重复出现，但不值得分别维护多个单用途工具。PowerToys 用一致的安装、升级和配置入口降低了切换与维护成本，已经成为 Windows 原生能力之外的默认补充，因此处于“采用”；这不表示所有模块都会启用。

我只在需求稳定后启用模块，与 Windows 原生功能或现有工具重叠时保留更顺手的一方。如果快捷键冲突、后台负担或稳定性开始干扰日常工作，或者系统原生能力已经覆盖当前用途，我会缩减使用范围并重新评估它的位置。
